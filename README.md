端到端会话加了密钥棘轮，抓包却发现历史消息能被新密钥解开，乱序消息还整批丢失：链派生只把计数喂进哈希，域分离完全不参与，同一计数在不同用途得到同一把密钥；链推进直接改写传入状态，失败后无法回滚，重试同一输入得到不同结果；跳号推进不设任何上限，一次要求跳到极大计数就能耗尽内存；跳号时把中间消息键全部丢弃，乱序到达的旧消息永久解不开；乱序缓存按插入先后淘汰，而不是按计数窗口淘汰，低计数旧键被新键挤掉；读取缓存键后不删除，同一密文可以再次取出同一消息键完成重放；链校验只看新旧链键是否非空，域不同的推进也被判为合法；链校验不要求计数只前进一步，跳级推进把中间链状态整段跳过；批量推进复用第一条事件的链键，第二个会话直接沿用第一个会话的链；消息键把计数按大端四字节拼接却不校验范围，超过四字节的计数被静默截断。ratchet/kdf.py 是核心，tests/unit/test_kdf.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。
